2. Problem & Solution

02 / 05
⚠️ The Problem (Old Manual System)
  • Lost Complaints: Paper register entries easily get misplaced, torn, or ignored.
  • No Live Tracking: Complainants have no idea who is fixing their issue or when it will be done.
  • No Photo Evidence: Verbal complaints fail to capture exact error codes or physical hardware damage.
  • Communication Delay: Manual assignment of technicians takes days instead of minutes.
🎯 The Solution (TMS App)
  • 100% Digital Tickets: Raise complaints in seconds from Mobile App or Web Portal.
  • Live Progress Tracking: Transparent stages: Pending ➔ Assigned ➔ In-Progress ➔ Resolved.
  • Photo Proof Upload: Attach photos directly from smartphone camera to verify the problem.
  • Exact Location Tagging: Structured hierarchy: Department ➔ Block ➔ Room.
Core Tech Stack

3. Technology Used

03 / 05
1. Frontend (Client)
  • React 18 (Web): Fast Single-Page Application for SuperAdmin dashboard and master management.
  • React Native (Expo): Cross-platform mobile app running smoothly on Android and iOS devices.
  • Axios HTTP: Seamless REST API integration with token handling.
2. Backend (Server)
  • Node.js & Express.js: Asynchronous, non-blocking REST API with 28+ modular endpoints.
  • JWT Authentication: Stateless token verification ensuring secure user sessions.
  • Role-Based Access (RBAC): Strict permission middleware separating Admin, Staff, and Users.
3. Database & Security
  • MongoDB NoSQL: High-speed document database storing users, tickets, and campus masters.
  • Mongoose ODM: Strict schema validation and relational references (`.populate()`).
  • bcryptjs Hashing: Salted password encryption preventing plain-text credential leaks.
End-to-End Workflow

4. How TMS Works

04 / 05
Step 01
Raise Ticket
User opens Mobile App, selects Department ➔ Block ➔ Room, chooses category (PC, Software, Network), and attaches a camera photo.
Step 02
Admin Assigns
SuperAdmin reviews incoming tickets in real-time on Web Portal and assigns the task to a specialized technician.
Step 03
Resolve on Site
Technician checks assigned ticket on Mobile App, visits the location, updates status to In-Progress, and rectifies the fault.
Step 04
Close & Report
Technician marks ticket as Resolved. System maintains complete audit log and generates department-wise metrics.
Outcome & Road Ahead

5. Benefits & Future Scope

05 / 05
⭐ Key Benefits of TMS
  • Zero Paperwork: 100% digital ticketing prevents lost records and saves stationery costs.
  • Fast Resolution: Direct routing to technicians cuts resolution time by up to 80%.
  • Total Transparency: Complainants can see real-time status updates at any time.
  • Dynamic IP Switcher: In-app server configurator in mobile app allows live demo testing effortlessly.
🚀 Future Enhancements
  • Push Notifications (FCM): Instant mobile alerts when a ticket is assigned or resolved.
  • Automated SLA Escalation: Auto-alerts HOD if a critical complaint is unattended for 24 hours.
  • AI Auto-Classification: Uses NLP to read complaint text and auto-assign technicians.
  • In-App Live Chat: Direct messaging between complainant and assigned technician.
